# Aster SSH 1.0.3

Aster SSH 是面向 Windows 10/11 x64 的本地 SSH / SFTP 客户端。界面沿用已确认的工作台原型，正式版本不包含模拟服务器或模拟命令。

## 安装与启动

运行 `AsterSSH-Setup.exe` 安装到当前用户目录，无需管理员权限。也可将便携包解压到任意有写入权限的目录，运行 `AsterSSH.exe`。

程序需要 Microsoft Edge WebView2 Runtime。当前 Windows 11 通常已提供；缺少时请从微软官方 WebView2 页面安装 Evergreen Runtime：
https://developer.microsoft.com/microsoft-edge/webview2/

## 工作区布局

顶部不再保留额外的品牌与工作空间栏，会话标签直接位于系统标题栏下。快速查找与主题切换位于会话标签行右侧。

会话标签行最左侧的面板按钮、左侧“连接管理”图标和 Ctrl+Shift+B 均可收起 / 展开连接栏，收起后保留窄图标栏。连接栏内也有收起按钮。此状态会保存，重启后沿用；收起和展开会自动调整终端尺寸，不断开 SSH。

默认使用“柔和浅色”：侧栏、文件面板和终端采用相近亮度的浅灰色，普通文字采用深灰色，选中状态、图表和常用 ANSI 终端颜色采用低饱和色。远程程序指定的真彩色仍由程序控制。偏好设置可切换为柔和深色，并调整终端字号；终端会同步切换配色。

从旧版首次升级到 1.0.3 时会应用柔和浅色；连接、凭据、字号、文件接收目录与面板收起状态继续保留。之后手动选择的主题会保存，后续启动沿用。

## 连接服务器

1. 点击“新建 SSH 连接”，填写名称、地址、端口和用户名。
2. 选择密码认证，或选择本机的 OpenSSH / PEM 私钥。PuTTY 的 `.ppk` 需要先通过 PuTTYgen 转换为 OpenSSH 格式。
3. 如需保存新凭据，勾选“加密保存新凭据”。私钥文件本身不复制到应用目录。
4. 首次连接核对 SHA-256 指纹，再选择“信任并保存指纹”。指纹发生变化时程序拒绝连接；请通过可信渠道核实，再检查数据目录中的 `known_hosts`。

连接使用标准 SSH 协议，密码不会在配置文件或连接导出中以明文出现。保存的密码及私钥口令使用 Windows DPAPI 加密，绑定当前 Windows 用户环境。迁移电脑应重新输入凭据。

## 终端

终端使用 xterm.js 和服务器 PTY，支持 ANSI 颜色、Unicode / 中文输入、窗口尺寸同步、远程命令历史以及 `vim` / `top` 等交互程序。具体命令和补全由远程 Shell 提供。

- Ctrl+K：查找连接。
- Ctrl+F：搜索当前聚焦的终端；Enter / Shift+Enter 查找下一个 / 上一个。
- Ctrl+Shift+C：复制选中文本。
- Ctrl+V 或 Ctrl+Shift+V：粘贴；多行粘贴会要求确认。
- Ctrl+Shift+N：新建连接。

工具栏可以重新连接、创建独立分屏、开启会话日志和配置本地端口转发。分屏建立独立 SSH 会话，关闭分屏会断开该会话。关闭有未完成传输的会话时会提示。

快捷命令点击后只填入终端，按 Enter 执行。可以在“快捷命令 → 管理命令”中编辑。

## 文件管理

连接后 SFTP 默认打开服务器主目录。文件路径与终端的工作目录独立；可以通过面包屑、主目录、上一级按钮或“跳转路径”切换。点文件可预览或编辑不超过 2 MB 的 UTF-8 文本；二进制、其他编码和更大的文件请下载处理。

上传按钮可选择多个文件，或选择一个文件夹；也支持将文件和文件夹拖入文件面板。文件夹递归传输，保留名称、子目录和空目录。每批最多 200 个根条目，单个根条目最多 50,000 个文件与目录，同时传输最多 3 个根条目。符号链接和特殊文件会在开始前提示，不自动跟随。

下载使用“本地接收目录”，不是逐个“另存为”。首次点击下载选择接收文件夹，之后按服务器上的原名进入该目录。可点击文件面板底部的“接收目录”更换位置。文件夹下载保留完整目录结构，完成后可在传输队列点击文件夹图标打开接收位置。

同名目标会提示合并文件夹或覆盖文件。进度来自实际字节数和目录条目数，可以取消；取消时保留已完成的文件，清理当前未完成文件的临时副本。不提供断点续传，重新开始前会再次确认覆盖。

在线编辑和覆盖上传使用临时文件与 `posix-rename@openssh.com` 安全替换；不支持此扩展的服务器仍可上传新文件和下载，但不能直接覆盖已有文件。编辑保存前检查文件修改时间与大小，发现冲突会拒绝保存；这无法识别同一时间粒度内、内容长度也相同的外部修改。

文件操作菜单支持下载、重命名、删除文件和删除空目录。删除不可撤销，不能删除根目录或登录主目录，不提供递归删除。

## 监控、转发与日志

监控通过独立 SSH exec 通道读取 Linux `/proc`、`df` 和 `/etc/os-release`，不需要服务器代理。每 3 秒仅采样当前选中连接；隐藏监控、窗口最小化或页面不可见时暂停。CPU 与网络速率从两次采样差值计算。没有所需 Linux 接口的系统显示“不支持”，终端和 SFTP 可继续使用。

磁盘空间逐项列出可读取的挂载点、设备、文件系统、使用量和可用量，不局限于 `/`。展开“物理磁盘”可查看设备容量与未挂载分区；设备树信息通过 `lsblk` 读取，受服务器权限与当前系统可见设备限制。缺少该工具时仍显示 `df` 读取到的挂载点，并注明未挂载设备信息不可用。占用数据缺失时显示未知，不显示成 0%。tmpfs 等内存文件系统和 loop 设备不列作硬盘。

本地转发只绑定 `127.0.0.1`，目标主机从 SSH 服务器侧访问。本地端口填 0 可自动分配。关闭会话时监听及转发连接一同关闭。

会话日志从开启记录后开始保存原始终端输出，可能含 ANSI 控制符和终端显示过的敏感内容。选择一个新文件保存；关闭日志或断开连接时关闭文件。

## 数据与迁移

数据默认位于 `%APPDATA%\AsterSSH`：

- `config.json`：连接元数据、DPAPI 加密凭据、快捷命令及偏好。
- `known_hosts`：已确认的 SSH 服务器公钥。

设置中可以打开该目录、导入或导出连接。导出不包含密码、私钥口令和私钥内容，但包含主机地址、用户名和私钥路径。导入会创建新的连接记录，不覆盖现有记录。卸载保留数据目录。

## 当前范围

当前交付 Windows x64 版本，提供密码 / 私钥认证、终端、SFTP 文件及文件夹递归传输、Linux 监控、会话日志和本地端口转发。尚未提供跳板机链、SSH Agent、二次交互认证 / OTP、SOCKS / 远程端口转发、云同步、自动更新、断点续传和会话录制回放。

应用及安装程序尚未使用商业代码签名证书签名。发布目录提供 SHA-256 校验值。
