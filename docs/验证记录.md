# 验证记录

自动集成测试使用随机主机密钥的本机回环 SSH 服务，SFTP 文件系统完全位于内存中，不访问或暴露用户文件。测试服务不随客户端分发。

已覆盖：

- 未信任主机在指纹校验完成前不发送密码；确认后完成真实 SSH 握手。
- 已保存指纹变化时拒绝连接，即使传入了新指纹也不会自动替换。
- 密码登录、带口令的 Ed25519 私钥登录。
- PTY 分配、终端中文输入输出、窗口 resize。
- SFTP 文件夹创建、中文文件名上传、列表读取、文本读取和保存。
- 外部文件版本冲突拒绝保存。
- 下载内容逐字节核对、重命名、删除普通文件和空目录。
- 本地端口转发连接到真实回环 TCP 服务并核对双向字节。
- Linux 监控数据解析。
- 等待中的传输取消，确认未产生远程文件。
- 终端不确认消费时发送端阻塞，确认后恢复，防止无限缓存。
- Windows DPAPI 加解密、重启读取配置、磁盘和导出中不出现明文密码。
- 文件夹递归上传与下载，核对中文名称、嵌套子目录、空目录和二进制文件内容。
- 目录合并 / 文件覆盖前强制确认，确认后核对覆盖结果。
- 拒绝 Windows 保留文件名、路径穿越字符和本地文件名冲突。
- Windows 关闭确认框的 Yes / No 映射，确认退出时允许关闭，弹窗故障不锁死窗口。

这些测试验证了协议与数据流，没有使用用户的实际服务器凭据。实际服务器的算法、策略和 Shell 差异仍需在连接时验证。

在 Wails 开发界面与真实 Go 后端之间，另外完成了文件夹下载（5 / 5 条目）及单文件下载。核对中文文本、二进制文件的 SHA-256 与上传源一致，空目录保留，下载文件使用原名。该流程未使用“另存为”。

界面操作在用户按下 Esc 后停止，未继续操作原生目录选择窗口；其后的检查仅通过代码、自动测试和安装包内容校验完成。

## 1.0.1 布局与磁盘监控

- 本地页面确认无额外顶栏；收起连接栏后主区域宽度从 698 增至 946 像素，连接栏隐藏，展开入口保留，无横向溢出。
- 解析测试覆盖根分区、NVMe 数据盘、带空格的挂载点、网络挂载、LVM、未挂载磁盘及分区。
- 校验同时支持数值 / 字符串形式的设备容量；排除内存和 loop 设备，重复挂载记录去重。
- 校验缺少 `lsblk` 时保留所有可读取挂载点，无法取得占用时不伪造 0%。
- 页面磁盘布局使用明确标识的示例数据验证，不连接或更改用户服务器。

## 1.0.2 柔和深色配色

- 统一面板、侧栏和终端的灰蓝色背景，替换原有明亮蓝紫色选中状态与常用 ANSI 终端色板。
- 浏览器检查实际 xterm.js 渲染的普通文字、ANSI 输出、文件表格、监控及偏好设置弹窗；使用明确标识的示例数据，不连接用户服务器。
- 校验主题切换和设置选项；旧版配置只迁移一次，随后手动选择浅色会在重启后保留，字号、历史行数和收起状态继续保留。
- 默认色值按 sRGB 计算，正文对背景约 9.1:1、次要文字约 5.4:1、终端普通文字约 9.9:1、主按钮约 4.9:1。终端启用 4.5 的最小文字对比度选项。
- 预览截图：`docs/images/soft-dark-1.0.2.png`。预览脚本位于 `scripts/`，不会随客户端分发。
- 完整构建通过 `go test ./...` 与 `go vet ./...`；校验安装包解出的客户端 SHA-256 与独立版一致，Windows 文件与产品版本均为 1.0.2。

## 1.0.3 柔和浅色配色

- 默认界面和终端统一为浅灰背景、深灰文字与低饱和蓝色；优化文件列表、监控、次要文字、弹窗和终端搜索栏。
- 终端根据主题选择对应 ANSI 色板，切换设置会立即更新已有终端。

- 使用 `scripts/Preview.mjs` 的本机示例数据检查配色，不连接用户服务器。截图保存在 `docs/images/soft-light-1.0.3.png`。
- 浏览器确认浅色、深色双向切换，终端同步重新着色，无横向溢出或控制台警告；完整构建的测试与静态检查通过，安装包解出文件的 SHA-256 与独立版一致，Windows 版本号为 1.0.3。
