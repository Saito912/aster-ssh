# Aster SSH 交互原型

面向桌面 SSH 客户端的本地 UI 原型，无外部依赖，不加载外部字体、脚本或图片。

## 打开

在此目录运行 `node server.mjs`，然后访问 http://127.0.0.1:4173 。也可直接打开 `index.html`。

## 可以体验

- 连接搜索、分组折叠、收藏筛选、新建模拟连接、多会话标签及关闭。
- 深浅主题、终端字号、命令面板（Ctrl+K）、快捷键提示。
- 模拟终端命令、历史记录、Tab 补全、终端搜索、独立分屏。
- 模拟文件系统浏览、新建文件夹、文件预览和编辑。
- 选择或拖入本地文件，体验上传队列；下载演示文本；取消传输。
- 模拟服务器指标，关闭监控或页面不可见时暂停刷新。
- 拖动终端与文件面板间的分隔条，调整文件面板高度。

## 原型边界

未实现真实 SSH、SFTP、凭据存储和系统窗口管理。所有服务器信息、文件目录、传输进度均为模拟。终端输入不会作为系统命令执行。

上传内容只在当前浏览器页面内存中使用，不发送到服务器；大于 1 MB 的文件只保留名称和大小。连接配置、收藏、主题和偏好保存在此浏览器的 localStorage，文件改动和终端会话不持久化。

下载用于体验文本文件流程；示例归档等大文件条目为占位文本，并非真实归档。

原型确认后，可将界面迁移到 Vue 组件，以 Wails + Go 接入真实 SSH / SFTP。此版本不能用于判断最终桌面应用的资源占用。
